# 🎯 AI Job Hunter (自动求职与智能联络智能体)

一套专为技术求职、兼职接单打造的**独立、安全、全天候本地自动化求职 Agent**。

> 💡 **完全独立部署与零环境依赖**：  
> 本项目为**完全独立的本地实例**。每位使用者只需克隆仓库，在自己电脑上运行，数据保存在本机的专属独立数据目录中，不依赖任何开发者的电脑环境、路径、数据库、Cookie 或云端服务！开箱即用、一键运行。

---

## ⚡ 核心能力与安全特性

1. **真实 Chrome 原生 CDP 调试接入**：
   - 基于原生 Python 实现 Chrome DevTools Protocol (CDP) 客户端，免 WebDriver 驱动特征，抗反爬检测；
   - 调试端口安全锁定仅允许 `127.0.0.1` 环回访问，移除通配 Origin，防止外部扫描；
   - 支持多实例端口动态探测与分配，不抢占无关的 9222 端口；
   - 拥有独立的求职浏览器用户目录，与日常个人浏览器配置和扩展物理隔离。
2. **多源职位智能采集与硬技能匹配**：
   - 自动采集 BOSS 直聘等平台目标岗位，结合用户画像严格基于真实能力证据（A/B/C/D 级证据）进行可行性评分与技能缺口分析。
3. **50~95 字自然去 AI 味口语化沟通**：
   - 杜绝长篇公文套话，一条消息只讲一件真实做成的事，自然引出落点提问，回复率高。
4. **9 重安全防御的简历附件自动同意机制**：
   - 在后台监听 HR 会话时，精准识别真正的简历附件请求；
   - 严格防范普通文字消息误触，防范点击错误按钮或拒绝按钮；
   - 自动防重、失败自动熔断并在页面状态异常时立即安全停止。
5. **本地独立数据空间与隐私安全**：
   - 所有配置、数据库、简历与聊天记录均存放于操作系统标准数据目录：
     - **Windows**：`%LOCALAPPDATA%\AIJobHunter`
     - **macOS**：`~/Library/Application Support/AIJobHunter`
     - **Linux**：`~/.local/share/ai-job-hunter`
   - 首次运行自动无损初始化，不覆盖已有配置；绝对不读取、不上传任何个人敏感凭据。
6. **安全加固的本地 WebUI**：
   - 提供可视化求职工作台，严格限制仅本机（127.0.0.1）访问，内置 CSRF 校验、路径穿越防护与请求体大小限制。

## 🚀 极速上手指南

### 第一步：获取代码与安装依赖

```bash
# 1. 克隆本仓库
git clone https://github.com/tomybelovedxin-pixel/ai-job-hunter.git
cd ai-job-hunter
```

- **Windows 用户（推荐一键配置）**：
  在 PowerShell 中右键以管理员或当前用户执行环境配置脚本：
  ```powershell
  .\setup_windows.ps1
  ```
  该脚本会自动检查 Python、Chrome、创建独立虚拟环境并安装所有依赖。

- **通用手动安装**：
  ```bash
  python -m venv .venv
  # Windows: .venv\Scripts\activate
  # Linux/macOS: source .venv/bin/activate
  pip install -r requirements.txt
  ```

---

### 第二步：一键初始化配置

运行初始化命令，系统会在你的独立本地数据目录生成专属配置模板：

```bash
python -m jobagent init
```
系统会自动将 `config.example.toml`、`profile.example.json`、`master_resume.example.json` 复制到独立数据目录供你填写真实信息。

---

### 第三步：启动与使用（两种方式）

#### 方式 A：Windows 一键批处理菜单（最简单）
在项目根目录下直接双击 **`run_windows.bat`**：
```text
========================================================
         AI Job Hunter 本地智能求职系统
========================================================
请选择要执行的操作:
  [1] 启动专属求职 Chrome 浏览器 (独立隔离配置)
  [2] 启动本地 WebUI 求职管理面板 (http://127.0.0.1:8765)
  [3] 启动后台 HR 聊天与简历请求自动同意守护 (Daemon)
  [4] 运行一轮职位抓取与匹配分析 (Pipeline)
  [5] 查看当前运行配置与本地数据目录路径
  [0] 退出
========================================================
```

#### 方式 B：终端命令行调用

```bash
# 1. 启动独立调试 Chrome（打开后在浏览器中登录求职账号）
python -m jobagent browser

# 2. 启动本地可视化求职控制台
python -m jobagent ui

# 3. 运行全量求职扫描与匹配管线
python -m jobagent run

# 4. 扫描指定关键词与城市岗位
python -m jobagent scan --query "Python兼职" --city "全国"

# 5. 启动后台 HR 会话实时监听与求简历请求自动同意守护
python tools/boss_chat_daemon.py
# 或使用内置命令：
python -m jobagent listen --interval 6
```

## ⚙️ 配置文件说明

所有个人配置文件位于操作系统的用户数据目录中（也可在项目根目录下自定义存放同名文件）：

- **`config.toml`**：求职关键词、城市范围、过滤薪资、CDP 调试端口、自动化扫描间隔等。
- **`profile.json`**：技术栈、核心优势、A/B 级真实交付案例、公司与岗位黑名单。
- **`master_resume.json`**：完整简历经历与代码交付成果（系统会根据具体 JD 动态裁剪优化单页定制简历）。

## 🛡️ 常见问题 (FAQ)

**Q：首次运行提示未检测到 Chrome 怎么办？**  
A：请确认电脑已安装 Google Chrome。直接执行 `run_windows.bat` 选项 1 或运行 `python -m jobagent browser`，系统会自动扫描常见安装路径并为您启动配置好的隔离求职窗口。

**Q：多台电脑运行会产生冲突吗？**  
A：完全不会。每个使用者的配置和数据库都在自己电脑的用户目录中，没有任何共享的中心服务器或硬编码路径。

**Q：自动同意简历附件安全吗？**  
A：系统实现了 9 重防误触与防重复校验：必须经过会话校验、卡片文本比对、按钮文本确认为“同意”或“发送”、点击结果状态复核与异常熔断机制，绝不会在未知状态下随意点击。
