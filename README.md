# 🎯 AI 专属求职与企业联络项目 (AI Job Hunter)

这是一个专为在 Antigravity 中进行**企业智能联络、岗位匹配与自动求职**打造的专属项目工作区。

---

## 🚀 如何在 Antigravity 中使用？

只需将当前工作区切换为本目录，或者直接在本项目的对话框中对我下达指令：

### 常用对话指令示例：
1. **“帮我联系 [公司名称/HR名称]”**
   - 自动核查历史记录（是否聊过、上次沟通结论）。
   - 分析目标岗位要求，从你的真实能力库中匹配最合适的经验。
   - 生成去 AI 味、口语化、50~95 字的打招呼话术。
   - 通过 Google Chrome 调试端口（CDP）打开聊天窗口或自动发送。

2. **“帮我看一下这个 JD [粘贴 JD 内容]，能不能投？”**
   - 自动进行交付可行性与能力断言匹配分析，给出真实匹配度和首条话术策略。

3. **“启动求职浏览器”**
   - 自动启动专用于求职联络的 **Google Chrome**（端口 9222，独立登录态目录），直接导航至 BOSS 直聘聊天页，方便保持登录态。

4. **“查一下今天的新岗位”**
   - 自动从各大官方与公开渠道检索并分析最新的匹配岗位。

---

## 🔒 核心保障
- **严格限定 Google Chrome**：所有自动化行为均运行在 Chrome 独立沙箱端口，绝不触碰 Edge（保障 Codex 独立运行）。
- **去 AI 味与真实性**：绝对不编造经历，严禁透露 AI 身份，口语化表达。
